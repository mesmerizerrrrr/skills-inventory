# 스킬의 한글 이름

> 유지보수용 양식이다. `skills/<카테고리>/<스킬명>/SKILL.md`로 복사한 뒤 식별 정보와 본문을 실제 지침으로 바꾸고 이 안내를 지운다. 필요 없는 절은 삭제한다.

## 목적과 범위

- 이 스킬로 완성할 결과물을 설명한다.
- 비슷해 보이지만 이 스킬을 적용하면 안 되는 작업이 있다면 구분한다.

## 작업 절차

1. 먼저 확인할 입력과 프로젝트 규칙을 적는다. 필수 정보가 없을 때의 처리도 필요한 경우에만 적는다.
2. 결과물을 만드는 데 필요한 핵심 절차와 판단 기준을 적는다.
3. 정확성을 위해 지켜야 할 고유 제약을 적는다. 일반적인 조언을 반복하지 않는다.

## 결과물과 확인

- 결과물의 위치나 형식은 필요한 경우에만 지정한다. 사용자의 명시적 요청을 우선한다.
- 실제 완료 여부를 확인할 기준을 적는다.
