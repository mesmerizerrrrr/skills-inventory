# 제작용 임시 자료

`backdata/`는 스킬을 만들 때 필요한 입력 자료를 임시로 다루는 폴더다. 이 안내 파일 외의 내용은 Git 배포 대상에서 제외하며, 완성된 스킬은 이 폴더에 의존하지 않는다.

- 실제 사용에 필요한 규칙·예시·자료만 정리하여 해당 스킬의 `references/`, `scripts/`, `assets/`에 포함한다. 최종 파일에서 사용할 내부 상대경로도 함께 정리한다.
- 조사 로그, 프로젝트·계정·커밋 식별 정보, 요청·분석 경위를 원본 보존이라는 이유로 복사하지 않는다. 별도 역사 문서로 옮겨 배포하지 않는다.
- 제작 자료를 제거해도 배포 파일과 현재 작업 입력만으로 스킬을 이해·적용·유지보수할 수 있어야 한다. 사용자가 보관 중인 원본 파일을 임의로 삭제하는 지침은 아니다.

작성·검증 기준은 [생성·유지보수 가이드](../skills/MAINTENANCE.md)를 따른다.
